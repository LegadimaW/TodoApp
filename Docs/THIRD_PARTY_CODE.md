# Third-Party Code

The TodoApp was developed using the following third-party libraries and packages:

| Package | Purpose |
|----------|----------|
| Next.js | Provides the React framework used to build the application's user interface, routing, and server-side functionality. |
| React | Used to create reusable user interface components and manage application state. |
| TypeScript | Provides static type checking to improve code quality, maintainability, and developer productivity. |
| Prisma ORM | Used to interact with the SQLite database through a type-safe API and to manage database schema migrations. |
| SQLite | Lightweight file-based database used to persist task information locally on the user's machine. |
| Tailwind CSS | Utility-first CSS framework used to build responsive and consistent user interfaces. |
| DaisyUI | Component library built on Tailwind CSS that provides pre-designed UI elements such as cards, buttons, badges, and modals. |
| ESLint | Used to identify and enforce coding standards and detect potential issues during development. |
